# Script migration contract

All reproducible code lives under `code/`, validation under `validation/`, and plot consumers under `plots/`. Canonical data remain at their external roots in `code/config/data_roots.m`; no old product files are copied. Formal products generated by migrated publishers must target `products/`.

The migration check is `code/validation/validate_script_migration.ps1` and rejects old project-root hardcodes in the formal code and validation trees.
